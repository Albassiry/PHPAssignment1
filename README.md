# Capstone Project Proposal
Name: IT Service Desk Manager
Introduction
IT Service Desk Manager is a web application prototype designed to help a small IT support team organize and track technical support requests. The application will provide one place to record support issues, identify their priority, track their status, and maintain a simple history of work. The first version will use PHP and MySQL for the backend, and later development will add an Angular frontend. The goal is to create a practical application that demonstrates database development, web application structure, version control, and the ability to learn and solve new development problems.
General Functionality
•	Create a new IT support ticket with requester information, subject, description, priority, and status.
•	Display a dashboard showing ticket totals by status.
•	View all support tickets in a table.
•	Edit ticket information and change ticket status.
•	Delete tickets when appropriate.
•	Store ticket information in a MySQL database.
•	Validate user input and use prepared SQL statements.
•	Develop a PHP backend first and later connect an Angular frontend through PHP API endpoints.
•	Use Git and GitHub Projects to manage tasks, versions, and development progress.
